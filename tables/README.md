# Machine-readable manuscript tables

Tables 1–4 reproduce the main manuscript tables. Tables S1–S27 reproduce Online Resource 1. Each UTF-8 CSV keeps the published row order, column order, displayed precision and units. Cells spanning multiple columns or rows repeat their value so spreadsheet readers can reconstruct the headers. In equation cells, `^(...)` marks a superscript and `_(...)` a subscript.

The index gives the caption and size of every table. For full protocol notes, read the manuscript and Online Resource 1. Some tables include published comparator values, dataset descriptions or protocol decisions alongside this study’s own results. Interpret those cells using their original labels and source citations. The values have the precision reported in the paper. The planned-steering files in the evidence directory retain additional precision for recalculation.
